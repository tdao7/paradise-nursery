# Publish to GitHub (tdao7)

This project is prepared for publication. The GitHub URLs below do not exist until the project has been published to a **public** repository named `paradise-nursery` in the `tdao7` account.

## Quick publish (macOS / Linux)

If GitHub CLI is not installed, run `brew install gh` on macOS (or follow https://cli.github.com/).

1. Unzip the submission and open a terminal in the extracted `paradise-nursery` folder.
2. Sign in once: `gh auth login`.
3. Run: `bash publish.sh`.

The script checks that the active GitHub login is exactly `tdao7`, initializes a local Git repository if needed, and creates a **public** `tdao7/paradise-nursery` repository before pushing all files.
